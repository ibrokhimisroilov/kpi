# KPI-бот «Эффективность» — карта проекта для Claude

Telegram-бот **@UzAuto_Administration_bot**: начальник ставит задачи, сотрудники сдают результат,
AI сравнивает план и факт, начальник подтверждает оценку, бот считает взвешенный KPI.
Плюс мини-приложение Telegram (дашборд, задачи, проверка, сдача). Заказчик — нетехнический
человек, **админ бота** (Telegram ID 7069811112); начальник, который работает в боте каждый день, —
другой человек (187462625). Общение с заказчиком **только на русском**. В текстах продукта —
«начальник», не «руководитель».

## Жёсткие требования заказчика

- **Всё бесплатно.** Никаких платных сервисов и карт. AI — бесплатный тариф Google Gemini
  (цепочка моделей → запасные бесплатные провайдеры → расчёт по правилам).
- **Минимум участия заказчика.** Не давать ему многошаговых технических инструкций: всё, что можно,
  делать самому; страницы открывать за него; шаг для него — один, простой, с точными названиями кнопок.
- Секреты (токен бота, ключи, пароль базы) в чат не просить и в веб-формы самому не вводить —
  это делает заказчик. Они лежат только в `.env`, `deploy/render.env` (в git не попадают) и в Render.

## Принятые продуктовые решения

KPI = Σ(вес×оценка)/Σ весов по сроку задачи в периоде; просроченная несданная задача = 0 %;
задачи на проверке в KPI не входят; оценка 0–150 %; штраф за просрочку 2 п.п./день, максимум 20;
часовой пояс Asia/Tashkent; тихие часы 21:00–8:00; сводка по понедельникам 9:00; копия базы 23:00.
Сотрудник не видит оценку AI до решения начальника.

**Автоподтверждение** (`bot/services/auto.py`, задание `jobs.run_auto_decisions`): начальник не ответил
за 24 ч (выходные считаются; ночью переносится на 8:00; за 3 ч — напоминание) — оценка AI становится
итоговой, поручение сотрудника принимается с весом от AI (`bot/ai/weigh.py`, иначе 10 %) и средним
приоритетом. Ждут начальника всегда: оценка «по правилам» (без AI), оценка выше 100 %, заявки на доступ.
Автоматически подтверждённую оценку начальник может изменить 7 дней (только оценку, не «на доработку»).
Отсчёт для того, что ждало до первого запуска функции, идёт от первого запуска.

**Голосовой ввод** (SPEC §13; `bot/ai/dictate.py`, `bot/voice.py`, `bot/handlers/voice.py`): речь на
узбекском и русском распознаёт бесплатный Gemini (узбекский — латиницей). На любой вопрос диалога о
задаче можно ответить голосовым; голосовое вне диалога — задача целиком (начальнику — черновик задачи,
сотрудника бот спрашивает: поручение или результат). ФИО при регистрации — только текстом. Запись до 2 мин.
В мини-приложении — микрофон у текстовых полей и «надиктовать задачу целиком» (`POST /api/voice`).

**Оформление приложения** (MINIAPP_SPEC §11.1, §11.3): эмодзи в приложении нет — значки рисует свой набор
линейных SVG (`ICONS` и `icon(имя)` в `app.js`; подпись кнопки со значком меняет `setLabel`, а не `setText`).
Подписи сервера по-прежнему приходят с эмодзи в начале (как в чате): приложение его убирает
(`stripLeadingEmoji`), значок берёт по полям `status` / `overdue` / `priority` или по самому эмодзи (`markIcon`).
Цвета, размеры шрифта и радиусы — только токены из начала `app.css` (цвета — из темы Telegram); утилиты — в
конце файла. За этим следят тесты в `tests/webapp/test_static_contract.py`; лимит `app.css` — 48 КБ.
Формы: поля — в карточках; основная кнопка активна всегда — нажатие подсвечивает пустое и называет его
(«Осталось заполнить: …», `formGuide` в `app.js`), а не блёкнет без объяснений.
Загрузка (MINIAPP_SPEC §11.5, §11.6): вкладка, открытая снова, сразу показывает прежний ответ (не старше
10 мин), свежий приходит следом — `stale: true` у `loadInto`, списки задач — всегда; формы и экраны решения
(проверка результата, поручение, правка, сдача) прежнее не показывают и отказу из кэша не верят (`recheck: cant(…)`:
«уже обработано» / «сдать нельзя» по карточке из кэша — сначала запрос к серверу). Пустой экран — с кнопкой, когда есть
честный следующий шаг (`emptyState(text, icon, action)`). Лимит `app.js` — 320 КБ (с раскладкой большого экрана сайта).

**Сайт** (MINIAPP_SPEC §15; настройка `WEBSITE_ENABLED`, по умолчанию включён): то же приложение в обычном
браузере по адресу бота — тот же `app.js` (режим `WEB`), тот же `/api/*`, те же права. Вход без пароля: сайт
показывает число, кнопку «Открыть Telegram» и QR-код ссылки `t.me/<бот>?start=login_<код>`; бот присылает три
числа и «Это не я»; верное число подтверждает вход в том браузере, который его начал. Попытка — 5 минут и один
раз; подтвердить может только открывший ссылку активный пользователь; сессия — 30 дней без обращений и не дольше
90 дней, в базе только SHA-256 (таблицы `web_logins`, `web_sessions` — в резервную копию не попадают); запросы
сайта несут `X-KPI-CSRF`, чужой `Origin` — отказ; блокировка сотрудника сразу удаляет его сессии сайта; под
сообщением бота о входе — «Выйти с сайта на всех устройствах»; «Выйти» не трогает Mini App. Файлы и Excel
по-прежнему приходят в чат с ботом. Стили сайта — `static/site.css` (лимит 24 КБ), страница — `static/site.html`.
Большой экран (MINIAPP_SPEC §15.6, только сайт): от 1024 px — боковое меню, таблицы с сортировкой (`dataTable`;
«Задачи» и «Мои задачи» сортирует сервер — параметр `sort` у `GET /api/tasks`), формы в две колонки, листы
окнами; от 1280 px — панель подробностей справа от списка (маршруты с `pane: true`, список слева — `under`).
До 1023 px — тот же вид, что в Mini App. В Mini App раскладка не меняется: `isWide()` и `hasPane()` истинны
только при `WEB`. Отступ под боковое меню — только под отметкой каркаса `body.has-shell` (экран входа и экраны
отказа стоят по центру). Права сайта равны правам Mini App по всем адресам API — `tests/webapp/test_site_rights.py`
(MINIAPP_SPEC §15.7; новый адрес API попадает в проверку сам, открытый сотруднику — добавить в `OPEN_TO_EMPLOYEE`).

**Два языка** (SPEC §14): каждый выбирает сам — русский или узбекский (латиница), по умолчанию язык
Telegram; кнопка меню «🌐 Til / Язык», `/lang`, в приложении — кнопка у заголовка. Переводится всё, что
пишет бот (чат, уведомления, приложение, Excel); тексты задач, ФИО, комментарии — нет. Тексты в коде —
по-русски; слова пользователя — через `esc()` / `own()` (в app.js — `own()`); новую фразу добавить в
`bot/i18n/catalog_uz.py` (чат, API, Excel) или в `UZ` (app.js). Непереведённое не ломается — остаётся
по-русски; найти: `tests/test_i18n.py` и сбор `TEST_I18N_MARKS=true I18N_COLLECT=файл.json pytest tests/e2e
tests/webapp`.
