# KPI-бот «Эффективность» — карта проекта для Claude

Telegram-бот **@UzAuto_Administration_bot**: руководитель ставит задачи, сотрудники сдают результат,
AI сравнивает план и факт, руководитель подтверждает оценку, бот считает взвешенный KPI.
Плюс мини-приложение Telegram (дашборд, задачи, проверка, сдача). Заказчик — нетехнический
руководитель, общение **только на русском**.

## Жёсткие требования заказчика

- **Всё бесплатно.** Никаких платных сервисов и карт. AI — бесплатный тариф Google Gemini
  (цепочка моделей → запасные бесплатные провайдеры → расчёт по правилам).
- **Минимум участия заказчика.** Не давать ему многошаговых технических инструкций: всё, что можно,
  делать самому; страницы открывать за него; шаг для него — один, простой, с точными названиями кнопок.
- Секреты (токен бота, ключи, пароль базы) в чат не просить и в веб-формы самому не вводить —
  это делает заказчик. Они лежат только в `.env`, `deploy/render.env` (в git не попадают) и в Render.

## Как работать

```bash
PYTHONUTF8=1 PYTHONIOENCODING=utf-8 ./.venv/Scripts/python -m pytest -q -p no:cacheprovider   # ~1550 тестов, ~2,5 мин
```

- PostgreSQL-прогон: `TEST_DATABASE_URL=postgresql://postgres:pgtest@127.0.0.1:55433/kpi_test`
  (локальный сервер поднимается пакетом `pgserver`; если не запущен — поднять заново во временной папке).
- Бюджеты обращений к базе: `tests/perf` и `tests/webapp/test_api_budget.py` — не ухудшать
  (обычный апдейт чата — 1–3 обмена с базой).
- Перед пушем: полный набор тестов, проверка, что секретов нет в индексе git.
- Проверка после деплоя без браузера: `getWebhookInfo`, `getChatMenuButton`, `GET /health`,
  запросы к `/api/*` с подписанным initData (см. `bot/webapp/auth.py`).
- Локальный просмотр мини-приложения: `python -m bot.webapp.dev` (временная SQLite, демо-данные).
- Локально бота в режиме polling не запускать, пока в Telegram стоит webhook (бот сам откажется).

## Принятые продуктовые решения

KPI = Σ(вес×оценка)/Σ весов по сроку задачи в периоде; просроченная несданная задача = 0 %;
задачи на проверке в KPI не входят; оценка 0–150 %; штраф за просрочку 2 п.п./день, максимум 20;
часовой пояс Asia/Tashkent; тихие часы 21:00–8:00; сводка по понедельникам 9:00; копия базы 23:00.
Сотрудник не видит оценку AI до решения руководителя.
